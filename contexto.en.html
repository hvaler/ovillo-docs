Skill listing

Claude sees a listing with the name and description of every model-invocable skill; workflows (disable-model-invocation) are left out. The description is cut at 1536 characters.

Measured, not assumed (ADR-040): the 13 path-scoped skills (paths:) do appear in the listing and are counted here. Until ADR-040 they were counted as 0, on an assumption that turned out to be false when checked against the model: in a directory where nothing matches, it still quotes their description. The sibling assumption does hold, which is why workflows stay out.

How to bring the cost down

  • Move layer conventions to path-scoped skills (paths:): they only load when those files are touched.
  • Shorten descriptions below the cap without losing the tokens that fire the evals (measure it with run_eval.py).
  • Reduce the consumer memory: a short CLAUDE.md and @imports only for what is stable.
  • Agents: a one-sentence description with USE FOR / DO NOT; the body costs nothing until it is invoked.
