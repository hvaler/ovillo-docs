The file names stay as they are: they are what the skills look for.

How they are used

These templates are used:

  1. By hand: copy one and adapt it to the project
  2. With /hv:prepara-entrega: Claude uses them to generate documentation
  3. With /hv:sync: Claude checks that the documentation still follows the structure

The template defines the structure; the project's document holds the specific content.
