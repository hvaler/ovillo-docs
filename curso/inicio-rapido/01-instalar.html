Lección 1Instalar el plugin y preparar el repositorio

1. Instalar el plugin y preparar el repositorio2. Onboarding con /hv:init3. Empezar un proyecto nuevo4. El flujo de trabajo y la configuración de la organización5. Validar la instalación y resolver problemas

Objetivos

  • Saber qué requisitos hacen falta y por qué solo el SDK de .NET es obligatorio
  • Instalar el plugin hv desde el marketplace ovillo
  • Dejar el repositorio listo para el onboarding

Contenido

Ovillo se instala como plugin de Claude Code: no copia ficheros en tu proyecto hasta que tú lo pides. En esta lección instalas el plugin y preparas el repositorio para que /hv:init tenga dónde escribir.

Requisitos

  • Claude Code y Node.js ≥ 18 (los hooks son Node).
  • SDK de .NET. Ningún IDE es requisito: la integración con Visual Studio o VS Code se activa por configuración (organization.ide en ecosystem.config.json).
  • git.
Paso 1: instalar el plugin (2 min)
claude plugin marketplace add hvaler/ovillo      # el repositorio es el marketplace
claude plugin install hv@ovillo

Se instala una vez por usuario. A partir de aquí todas las skills se invocan con el prefijo /hv: y los agents como hv:<agent>.

Paso 2: preparar el repositorio (1 min)
cd C:\MiProyecto
claude
/hv:init

/hv:init escribe en el repositorio lo que un plugin no puede llevar, y nunca pisa lo que ya existe:

  • el layout src/ docs/ ops/ _hilo/ _patron/ con sus README;
  • el Hilo (_hilo/, memoria del proyecto) vacío de arranque;
  • el Patrón (_patron/, base de conocimiento de la organización);
  • CLAUDE.md, las 3 reglas incondicionales y la configuración de Claude Code;
  • .vscode/ si organization.ide es vscode, o el script de Solution Folders si es visual-studio.

Si el código vive en la raíz del repositorio, /hv:init lo detecta y propone los git mv a src/; no mueve nada por su cuenta. Con --dry-run muestra el plan sin escribir.

Caso práctico

Tienes una solución .NET 8 con tres proyectos y un README.md de 2019. Instala el plugin, abre Claude Code en la raíz y comprueba con /hv: que aparecen las skills. No ejecutes todavía /hv:init: mira primero qué ficheros existen en la raíz y anota cuáles crees que va a crear. En la siguiente lección lo comprobarás.

Resumen

  • Dos comandos instalan Ovillo en cualquier proyecto; el plugin no toca el repositorio hasta que ejecutas /hv:init
  • Git es el único VCS soportado; el IDE es opcional y se declara en la configuración
  • Con el plugin instalado, las skills aparecen al escribir /hv:
