Se ejecuta solo bajo peticion explicita: invocacion de la skill documentacion-tecnica con intencion de aplicar, o una peticion de accion clara. El disparo semantico de la skill NUNCA llega hasta aqui: responde con el conocimiento del SKILL.md y para.

Genera documentación técnica del código fuente ubicado en src/.

USE FOR: documentación TÉCNICA del código (arquitectura, APIs, clases) para desarrolladores. DO NOT USE FOR: manuales FUNCIONALES para usuarios finales, QA o Product Owners → usar /user-documentation.

🧠 Extended Thinking Mode

think hard - Analiza el código en profundidad para generar documentación precisa y útil.

IMPORTANTE: Estructura de Carpetas

MiProyecto/
├── _hilo/                  ← Contexto del proyecto
│   ├── FUNCIONALIDADES.md
│   └── DEPENDENCIAS.md
├── src/              ← CÓDIGO FUENTE A DOCUMENTAR ⭐
│   ├── MiSolucion.sln|.slnx    ← .slnx solo .NET 8+
│   ├── MiProyecto.API/
│   └── ...
└── docs/           ← DOCUMENTACIÓN GENERADA ⭐
    ├── API/
    │   └── README_API.md
    ├── Arquitectura/
    │   └── ARQUITECTURA.md
    ├── Code/
    │   └── [Proyecto]/
    └── README.md

Parámetros

ParámetroDescripción
--apiDocumentar endpoints de la API
--codeDocumentar clases y métodos principales
--readmeGenerar README.md del proyecto
--fullDocumentación completa (default)
[ruta]Archivo o carpeta específica a documentar

Ejemplos de Uso

# Documentación completa
/documentar

# Solo documentar API
/documentar --api

# Documentar un archivo específico
/documentar src/MiProyecto.Domain/Services/ScholarshipService.cs

# Documentar un proyecto completo
/documentar src/MiProyecto.Domain/

Tareas a Ejecutar

1. Analizar Código Fuente

# Detectar proyectos en src/
$projects = Get-ChildItem -Path "src" -Filter "*.csproj" -Recurse

# Contar archivos por tipo
$csFiles = Get-ChildItem -Path "src" -Filter "*.cs" -Recurse |
    Where-Object { $_.FullName -notmatch "\\(bin|obj)\\" }

2. Generar Documentación de API (--api)

Buscar Controllers en src/:

$controllers = Get-ChildItem -Path "src" -Filter "*Controller.cs" -Recurse

Crear docs/api/README_API.md:

# Documentación de API

## Resumen
- **Versión**: [detectada]
- **Base URL**: [detectada de launchSettings.json]
- **Autenticación**: [JWT/Azure AD/etc.]

## Endpoints

### 📋 ScholarshipsController
Base: `/api/scholarships`

| Método | Ruta | Descripción | Auth |
|--------|------|-------------|------|
| GET | `/` | Lista todas las scholarships | 🔒 |
| GET | `/{id}` | Obtiene scholarship por ID | 🔒 |
| POST | `/` | Crea nueva scholarship | 🔒 Admin |
| PUT | `/{id}` | Actualiza scholarship | 🔒 Admin |
| DELETE | `/{id}` | Elimina scholarship | 🔒 Admin |

#### GET /api/scholarships
**Descripción**: Obtiene listado paginado de scholarships.

**Parámetros Query**:
| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| page | int | No | Página (default: 1) |
| pageSize | int | No | Tamaño (default: 10) |
| estado | string | No | Filtro por estado |

**Respuesta 200**:

{ "data": [...], "total": 100, "page": 1, "pageSize": 10 }


**Códigos de Error**:
| Código | Descripción |
|--------|-------------|
| 401 | No autenticado |
| 403 | Sin permisos |
| 500 | Error interno |

3. Generar Documentación de Código (--code)

Analizar clases principales en src/:

# Buscar servicios, repositorios, entidades
$services = Get-ChildItem -Path "src" -Filter "*Service.cs" -Recurse
$repositories = Get-ChildItem -Path "src" -Filter "*Repository.cs" -Recurse
$entities = Get-ChildItem -Path "src" -Filter "*.cs" -Recurse |
    Where-Object { $_.Directory.Name -eq "Entities" -or $_.Directory.Name -eq "Models" }
