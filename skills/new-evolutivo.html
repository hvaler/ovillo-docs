Contenido

English name for /hv:nuevo-evolutivo. This skill adds no behaviour of its own: it exists so that an English-speaking team can find and type the workflow without learning its Spanish name. The canonical name does not change — it is a contract (ADR-077, ADR-080).

User only: it carries disable-model-invocation: true, like the workflow it points at. Without that flag an alias would be a back door around the invariant a workflow never fires on its own.

What to do

Read ${CLAUDE_PLUGIN_ROOT}/skills/nuevo-evolutivo/SKILL.md and follow it exactly, as if the user had typed /hv:nuevo-evolutivo, passing along any arguments they gave.

Read the file — do not try to invoke /hv:nuevo-evolutivo: it is a workflow, so the model cannot fire it, and telling the user to type it again would make them do the work twice.

If ${CLAUDE_PLUGIN_ROOT} is not set (the ecosystem was installed from the zip instead of the marketplace), the same file is at .claude/skills/nuevo-evolutivo/SKILL.md.
